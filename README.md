# Serviimo

> ⚠️ **Heavily work in progress.** Some functions work, some don't. Any
> contribution really helps — here or in the sibling ecosystem modules
> ([AniiModLoader](https://github.com/CyrixJD115/AniiModLoader),
> [Apiimo](https://github.com/CyrixJD115/Apiimo)) — all coordinated from
> [AniiStudio](https://github.com/CyrixJD115/AniiStudio).

A personal-use reimplementation of the Aniimo server side.
See PLAN.md for feasibility, architecture, and the tiered roadmap.
Status: skeleton only - stub crates plus the plan; nothing serves yet.

**Scope of use:** Serviimo is a private, self-hosted server for your own
legitimately owned copy of the game and your own account. It is the intended
companion for [AniiModLoader](https://github.com/CyrixJD115/AniiModLoader)
mods. It is **not** a tool for cheating on, attacking, or interfering with
the official Aniimo servers or any other online service.
